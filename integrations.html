What is required to activate connections?

1. Account storage
Configure the existing Cloudflare D1 binding JT_AUTH_DB. Connector records and encrypted credentials must be stored per JT account.

2. OAuth applications
Create an OAuth app with each provider and register the exact callback URL shown in its setup instructions. Provider client secrets belong in Cloudflare Pages secrets, never in browser JavaScript or GitHub source.

3. Token protection
Use a server-side encryption key, short-lived OAuth state, callback validation, token refresh handling and disconnect/revocation support.

4. Jeff AI tools
Expose narrow tools such as search_files or list_issues. Separate read and write scopes; ask for confirmation before sending messages, changing records, publishing, deleting or making financial changes.

5. Test each integration
Verify sign-in, granted scopes, tool execution, failure handling, audit events and disconnect. Only then should a connector display Connected.
