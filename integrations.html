Configure Cloudflare and account storage

1. Create the D1 database
Open the Cloudflare dashboard → Workers & Pages → D1 SQL Database → Create database. Name it jt-auth-db.

2. Create the tables
Open the database → Console, then run the SQL in db/auth-schema.sql from the GitHub repository.

3. Bind D1 to Pages
Open Workers & Pages → jt-digital-world-new → Settings → Functions → D1 database bindings. Add variable name JT_AUTH_DB and select jt-auth-db.

4. Add provider secrets
In the Pages project → Settings → Variables and Secrets, add the secret names shown above. For Cloudflare API access, also set CLOUDFLARE_ACCOUNT_ID. Use a narrowly scoped API token. Do not put secrets in GitHub source files or frontend code.

5. Redeploy and verify
Trigger a new deployment, then reload this page. Status changes to Connected only when the server can see the required configuration.

D1 binding and API secrets are account-level setup steps. This page cannot create them inside your Cloudflare account without an authorised Cloudflare connection.
