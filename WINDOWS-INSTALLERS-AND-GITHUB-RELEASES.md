# JT Digital World Windows installer releases

## Installer experience

Each desktop app uses the standard, maintained electron-builder NSIS wizard with JT branding, a selectable install directory, Start Menu and desktop shortcuts, and a separate Windows uninstall entry. Each app has a stable app ID so future releases can upgrade the same app rather than register as a different product. The uninstaller is generated by electron-builder; no custom replacement uninstaller is used.

Uninstalling an app should not remove other JT apps. App-specific user settings are preserved by default; the user can remove them separately if needed. Do not delete shared JT AI Core data as part of an individual app's uninstall.

## Output files

For each of the nine apps, the build produces two Windows EXEs under `Build/release/individual/<app-id>/`:

- `<JT-app>-Setup-<version>-x64.exe`: normal installer wizard; use this for the app's GitHub Release download.
- `<JT-app>-Portable-<version>-x64.exe`: portable build; it does not install into Windows or provide the normal uninstall entry.

The build verifier checks that both outputs exist for every app before release.

## Publish a GitHub Release

1. Commit and push the project to GitHub.
2. Create and push a version tag, for example `v60.0.1`, only after the version has been tested.
3. In GitHub, open **Actions** and monitor **Build JT Windows Installers**.
4. The workflow checks source syntax, builds all nine apps on Windows, verifies that every setup and portable EXE exists, then attaches the EXEs to the tagged GitHub Release.
5. Download each setup EXE from the draft/published release and test install, launch, upgrade, and uninstall on a clean Windows 11 test account before treating it as production-ready.

You can also run the workflow manually. A manual run uploads a downloadable Actions artifact; a GitHub Release is created/updated automatically only for a pushed `v*` tag.

## Important quality gate

A successful file build is not equivalent to a fully tested installer. Before a public release, test all nine apps on Windows 11, confirm the uninstall entries and shortcuts, verify app-to-app/shared-core behavior, and scan/sign binaries as appropriate. Unsigned installers may show Windows SmartScreen warnings. Do not claim a digital publisher identity until a code-signing certificate has been configured.
